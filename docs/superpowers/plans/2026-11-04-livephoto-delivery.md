# 实况照片交付改造

目标：用户选择视频和片段后，在 Mac 直接保存为相册中的一张实况照片；文件导出仅交付一个 Motion Photo，不再要求用户选系统、模板或手工配对。

证据：旧核心默认输出三份文件；静图 UUID 依赖 donor/exiftool，MOV 缺关键帧时间轨；同步编码阻塞 Electron 主进程；按输入 stem 直接输出会覆盖同名素材；旧测试依赖未入库视频。

方案：保留 React/Electron/FFmpeg。FFmpeg 负责统一裁剪与编码，Mac 原生 Swift helper 使用 ImageIO 写静图标识、AVFoundation 写 MOV 标识及 still-image-time 轨、PHLivePhoto 验证，PhotoKit 写相册。Swift helper 打包时编译，运行时不要求 Swift/Xcode。不引入网络服务或声称全平台全应用兼容。

1. 原生桥接：prepare/validate/import 三个命令；JSON 结果、非零退出表示失败；只接受最终非 degraded 校验结果。仅添加权限下报告写入完成，不谎称完成读取验证。
2. 转换核心：destination=photos|file，照片资源只驻留临时目录；文件导出用排他写入自动编号；统一验证时间范围，素材不放大，失败清理临时资源。删除旧二进制 MOV 手写、donor 和 exiftool 路径。
3. 调度：后台 worker 串行处理视频，主进程异步探测素材；同一时刻只运行一批，逐条返回阶段和结果；订阅在 React 卸载时清理。
4. 界面：保留现有两栏工作台，收敛为素材/片段/保存位置；Mac 默认照片，其他系统默认文件；结果每个输入一条，错误可见；去掉壁纸保证和平台适配承诺。
5. 验证：自动合成短片覆盖导出结构、重复文件名、输入保护、时间边界、失败清理；Mac 核对共享 UUID、时间轨及系统加载；构建和实际窗口检查。相册实际写入涉及用户照片库，自动测试不写入，最终说明这一限制。

状态：实现与本机验证完成。

验证记录：
- 自动合成视频，核心回归通过：时间范围、源文件保护、重名排他导出、XMP 主图长度规则与 JPEG/MP4 边界、静音/解码、Apple 资源系统识别、拒绝不配对资源。
- 实际 Electron 33.4.11 的 preload/IPC、素材读取、缩略图解码、界面按钮导出、进度事件、后台期间主进程响应、900×640 布局通过。截图发现并修复旧 CSP 阻止 data 图片的问题。
- Swift 原生组件编译和 iOS 源码类型检查通过。
- macOS arm64 应用目录打包通过；打包运行检查发现资源路径只读问题，已通过独立资源参数修复并重新检查。

## 交互更新：视频预览与时间线截取

用户要求以剪辑软件的方式拖选片段，替代手填秒数。视频级 `clip={start,end,cover}` 成为选段的唯一归属，IPC 调度逐个迁移到各自选段；全局只保留声音/保存位置。新增 VideoEditor：本地预览、8 帧时间线、起止拖柄、播放线、键盘微调、选段播放和当前帧设封面。

Electron 33 的 net.fetch(file:) 对 Range 请求返回 200，视频 seekable 为 [0,0]；因此改用明确的 206/Content-Range 分段流响应。只服务已选择视频的随机标识；不放开任意本地路径。播放器拒绝源格式时用 FFmpeg 生成低分辨率预览，错误显式呈现，导出仍用源文件。

新增验证已通过：真实鼠标拖动起终点、键盘定位与封面、终点暂停、AVI 预览转码、素材切换保留选段、导出视频时长与选段一致；协议测试覆盖分段、后缀范围、非法范围。最终应用包已更新，打包环境的预览跳转、后台探测、文件导出和 Apple 素材验证均通过。900×640 窗口检查与实际截图确认预览保持原始比例；照片图库真实写入与手机分享的既有限制不变。

## 界面收敛：照片工具而非工程面板

保留已经验证的预览/截取契约，移除常驻设置侧栏，采用居中视频工作区、轻量素材条和底部保存栏。减少分辨率、文件体积、精确时间刻度、技术说明和重复卡片；声音与保存位置以内联控件呈现，兼容说明及失败日志按需展开。视觉使用温和的浅色中性色与低饱和绿，暗色视频预览保留真实画面对比。验证以实际截图、现有交互回归和打包运行检查为主，不添加纯视觉单元测试。

本轮视觉收敛验证完成：空状态与导入后实际截图已检查；900×640 窗口、声音开关、保存下拉选择、时间线拖选/键盘定位/封面/播放终点、每素材范围及导出时长回归通过。Mac 应用目录已重新打包，随包运行的预览跳转与文件转换检查通过。未新增依赖或改动转换格式。

## 导出前成片预览

核心分成 prepareDelivery / savePrepared：prepare 在临时目录生成最终封面、编码片段与目标资源，save 原样交付。核心直接调用者 processVideo 通过同一套流程完成，不保留第二套编码。主进程使用与窗口绑定的临时成片批次，IPC 仅返回不透明资源 URL 和批次 ID；确认只能消费对应批次，不能传入另一套参数。

界面主按钮改为「预览并保存/导出」，预览对话框展示实际封面，点击播放编码后的选段，可逐张查看批量成片。返回调整释放批次，生成中关闭则丢弃稍后完成的结果，避免旧预览覆盖新设置。单项生成失败保留错误且不伪装成功；用户可只确认成功生成的成片。窗口销毁时释放所属的已生成批次。

验证包括临时生成不写目标目录、实际时长/静音/封面及最终文件字节一致性，Apple 素材系统识别，真实桌面成片播放/批量浏览/返回调整/重新生成/确认交付。2026-11-05 验证完成：生成中关闭不会再次弹出旧结果或写出文件，批量失败项不会被当成成功，修改后重新生成的成片时长正确。打包应用中的实际封面/编码视频资源加载、确认交付与 Apple 素材识别均通过。照片图库实际写入和手机端兼容仍未实测。
