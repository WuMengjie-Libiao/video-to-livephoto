# Mac 历史素材导入

新转换请直接使用桌面应用的「保存到照片」。它会自动生成完整配对资源并保存，无需手动执行脚本。

本目录保留旧的成对文件导入入口，与桌面应用共用原生验证和写入实现：

```bash
cd desktop
npm run build:native
cd ..
swift macos-import/pair.swift /绝对路径/test.JPG /绝对路径/test.MOV
```

输入必须已经是合法配对资源；此入口不会修补旧文件缺失的标识和关键帧时间轨。不匹配的资源会报错，请用新桌面应用从原视频重新转换。

首次写入会请求添加照片权限。这里只报告系统验证与照片写入完成，不会以仅添加权限伪装成已完成图库回读。iCloud 同步和 iPhone 播放仍需设备确认。
